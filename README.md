## 🖥️ Your First 5 Minutes With swarm-forge

Let's walk through a quick example so you can see the magic happen.

### Creating Your First Swarm

1. **Open swarm-forge**
2. Click the big **"New Swarm"** button
3. Give your swarm a name — like "Research Team" or "Creative Crew"
4. Click **"Add Agent"** — you'll see a list of pre‑configured AI agents with friendly names like "Summarizer", "Researcher", "Writer", and "Critic"

### Assigning Tasks

Each agent has a simple text box under its name. Type what you want that agent to do:

- "Summarize this article"  
- "Find five facts about renewable energy"
- "Write a short introduction"

You don't need to write code or connect anything — just type your request in plain English.

### Running the Swarm

Hit **"Start"** and watch the magic happen:

- Each agent lights up when it's working
- Messages move between agents in real time
- The final output appears in the right‑hand panel
- You can see a full history of what each agent did

When you're happy with the result, click **"Export"** to save the output as a text file or copy it to your clipboard.

## 🛠️ Troubleshooting Common Issues

### "I can't find the downloaded file"

- Check your **Downloads** folder (usually at `C:\Users\YourName\Downloads`)
- Press `Ctrl + J` in your browser to view recent downloads

### "Windows says the app is untrusted"

- Right‑click the downloaded file and choose **"Properties"**
- Check the box that says **"Unblock"**
- Click **"Apply"** and try again

### The app doesn't open

- Make sure you have at least 200 MB free space
- Restart your computer and try again
- Check your internet connection — swarm-forge needs web access for AI agents to work

### Agents are not responding

- Check that your internet is stable
- Wait a few seconds and try again
- Restart the app if the issue continues

If you still have trouble, visit the [GitHub page](https://github.com/alphaaero4-hash/swarm-forge) and look for the **"Issues"** tab to ask for help.
